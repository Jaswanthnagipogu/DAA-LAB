**Practical -7: COIN CHANGE PROBLEM 

SUMMARY:

This program solves the Coin Change Problem using the Dynamic Programming technique.
It finds the minimum number of coins needed to make a given amount by storing previously calculated results in a DP array. 
This avoids repeated calculations and makes the solution efficient.

CONCLUSION:
The Dynamic Programming approach provides an efficient and reliable solution to the Coin Change Problem. 
It reduces unnecessary computations, gives the minimum number of coins required, and works well for larger input values.
It is a simple and effective algorithm commonly used in DAA.
