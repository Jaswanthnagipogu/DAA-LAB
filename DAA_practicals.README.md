Practical 2: Linear search and Binary search

Summary:

This project demonstrates the implementation of Linear Search and Binary Search. The program provides a simple way to learn how different searching techniques works and time complexities of them.

Conclusion:

The project shows that Linear Search is simple and works on any list, but its performance decreases as the size of the data increases. Binary Search on the other side, is much faster for sorted data because it repeatedly divides the search space in half.Like taking mid element and comparing left side and right side. By comparing both algorithms on the same input, binary search is much better ofr large sorted datasets.



Practical 3 : Max Heap sort

Summary:

This project implements the Heap Sort algorithm to sort a list of numbers in ascending order. The program takes user input, builds a max heap from the given data, and repeatedly moves the largest element to its correct position until the entire array is sorted. It is a simple implementation that helps understand how Heap Sort works step by step.

Conclusion:

This project shows how Heap Sort can efficiently sort data using a binary heap. Although the algorithm is a little more complex than basic sorting methods like Bubble Sort or Selection Sort, it performs much better on larger datasets with a time complexity of O(n log n). finally this is helpful for me to understand the concept of heap sort and its effiency
