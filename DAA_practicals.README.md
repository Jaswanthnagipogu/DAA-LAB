Practical 2: Linear search and Binary search

Summary:

This project demonstrates the implementation of Linear Search and Binary Search. The program provides a simple way to learn how different searching techniques works and time complexities of them.

Conclusion:

The project shows that Linear Search is simple and works on any list, but its performance decreases as the size of the data increases. Binary Search on the other side, is much faster for sorted data because it repeatedly divides the search space in half.Like taking mid element and comparing left side and right side. By comparing both algorithms on the same input, binary search is much better ofr large sorted datasets.
