Summary:

This project implements the Heap Sort algorithm  to sort a list of numbers in ascending order. 
The program takes user input, builds a max heap from the given data, and repeatedly moves the largest element to its correct position until the entire array is sorted.
It is a simple implementation that helps understand how Heap Sort works step by step.

Conclusion:

This project shows how Heap Sort can efficiently sort data using a binary heap.
Although the algorithm is a little more complex than basic sorting methods like Bubble Sort or Selection Sort, it performs much better on larger datasets with a time complexity of O(n log n).
