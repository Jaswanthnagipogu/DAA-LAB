Practical 6: Matrix Chain Multiplication

Summary:
In this practical, I implemented the Matrix Chain Multiplication algorithm using Dynamic Programming. 
The program calculates the minimum number of multiplications needed to multiply a sequence of matrices by checking different possible orders. 
It stores the results in a DP table, which helps avoid repeated calculations.

Conclusion:
This practical helped me understand that the order of multiplying matrices plays an important role in reducing the computation cost.
I learned how Dynamic Programming finds the most efficient multiplication order and improves the performance of the algorithm.
Overall, this practical strengthened my knowledge of optimization techniques and Dynamic Programming concepts.
