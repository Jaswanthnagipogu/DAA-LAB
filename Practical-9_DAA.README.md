Practical-9:Implementation of Prism's Algorithm

Summary:

The Prim's Algorithm program finds the Minimum Spanning Tree (MST) of a weighted graph.
It starts from vertex A, selects the edge with the smallest weight at each step, and connects all vertices without creating a cycle.
The final MST has the minimum total weight.

Conclusion:

Prim's Algorithm is an easy and efficient method to connect all vertices with the minimum possible cost.
In this program, the minimum spanning tree is formed successfully with a total weight of 9.
