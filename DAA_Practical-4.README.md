Practical -4 : Recursion and Iteration

Summary:

In this practical, Recursion and iteration are two common techniques used in Design and Analysis of Algorithms.
Iteration uses loops to repeat tasks efficiently, while recursion solves problems by breaking them into smaller subproblems using function calls.
Both approaches are useful, and the choice depends on the problem and performance requirements.

Conclusion:

From this i can say that, Iteration is generally faster and more memory-efficient, whereas recursion provides a simpler solution for recursive problems.
Understanding both techniques helps in designing efficient and optimized algorithms.
