Practical 1 : Sorting techniques 
📋 Summary:

This project helped me understand how different sorting algorithms work in practice.
I implemented Insertion Sort, Merge Sort, Quick Sort, Bubble Sort, and Selection Sort from scratch using Python. 
While all of them produce the same sorted result, they differ in how they process data and how much time they take. 
By measuring the execution time and comparing their complexities, I gained a better understanding of which algorithms are more efficient for different types of data.

✅ Conclusion:

Working on this project improved my understanding of sorting algorithms and their real-world performance. 
I learned that Merge Sort and Quick Sort are generally more efficient for larger datasets because of their O(n log n) average time complexity, while Insertion Sort, Bubble Sort, and Selection Sort are simpler and easier to understand but become slower as the amount of data increases. 
Overall, this practical strengthened my knowledge of algorithm design, time complexity, and Python programming.
