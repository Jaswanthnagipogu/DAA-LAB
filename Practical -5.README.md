Summary:
In this practical, I learned how the Knapsack Problem can be solved using Dynamic Programming.
The program checks different combinations of items and finds the maximum value that can be carried without crossing the given weight limit.
Using a DP table made the solution faster because it avoids calculating the same values again and again.

Conclusion:
This practical helped me understand how Dynamic Programming is useful for solving optimization problems.
I learned how to find the best combination of items to get the highest profit within the given capacity.
It also improved my understanding of DP tables and how they reduce the overall time complexity of the algorithm.
